# 🔐 Modern Animated Login & Registration UI

This project is a **modern login and registration interface** built using **HTML, CSS, and JavaScript**, featuring smooth UI transitions between login and signup forms.

---

## 🚀 Features

* 🔄 Smooth transition between Login & Register forms
* 🎨 Modern and clean UI design
* ⚡ Interactive button-based state switching
* 🧩 Simple and responsive layout structure
* 💡 Lightweight and beginner-friendly code

---

## 🧠 How It Works

* A main container holds both login and register forms
* Clicking **Register** adds an `active` class to the container
* Clicking **Login** removes the `active` class
* CSS handles animations based on the active state
* JavaScript controls the UI state switching

---

## 🛠 Tech Stack

* HTML5
* CSS3 (Transitions & Animations)
* JavaScript (DOM Manipulation & Events)

---

## 📂 Core Logic

* `registerBtn` → Adds `active` class to show register form
* `loginBtn` → Removes `active` class to show login form
* Uses simple class toggling for smooth UI animation
